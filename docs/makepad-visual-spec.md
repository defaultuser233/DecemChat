# Makepad 版视觉对齐规格（以网页版 `src/**` 为准）

> 生成：2026-10-17，来源是对 `src/**` 的逐文件量取（Tailwind 类已换算成 px）。
> 用法：实现 Makepad 版 UI 时照这份数值做。**冲突时以 `src/**` 源码为准**，改了网页版要回来同步这份。
> 相关：`docs/makepad-migration.md`（迁移状态与坑）。

## 1. 整体

- **背景**：纯黑 `#000000`（不是现在的深灰）。
- **背景光晕**：三层 radial-gradient，都带 `animate-pulse-glow`（3s 循环，opacity 0.3↔0.6、scale 1↔1.1）：
  - 珊瑚 `rgba(243,129,129,0.4)`，384×384，约在左上 1/4 处，blur 60px，自身 opacity 0.2
  - 薄荷 `rgba(149,225,211,0.4)`，320×320，右下 1/4，blur 50px，opacity 0.15
  - 黄 `rgba(252,227,138,0.4)`，256×256，右上 1/3，blur 40px，opacity 0.1
  - ⚠️ **光晕极淡**：orb opacity × 动画 opacity 相乘，峰值只有 3–6%。自绘很容易画太重。
- **噪声层**：全屏 opacity 0.03 的 fractalNoise（可选，优先级最低）。
- **宽度**：顶栏与输入区**全宽**；**只有消息列**是 `max-w-3xl`=768px + 居中。
- **字体**：正文 Lato、标题 Poppins、代码 Fira Code/Consolas。Makepad 用自带字体族，**字形会有差别，不做像素级对齐**。
- 全局有 0.3s 的颜色过渡（`App.css:4-8`）。

## 3. 消息气泡（`MessageBubble.tsx`）

- 行：`gap: 12`、**顶对齐**（不是垂直居中）；char 头像在左、用户头像在右。
- 头像：40×40 圆形、2px 边框（用户 `#F38181`／char `#95E1D3`）；char 带 4s 呼吸动画；hover 时 scale(1.1) rotate(5deg)。
- 内容列：最大宽度 **75%（相对 768 的消息列）**，char 左对齐、用户右对齐。
- 气泡内距 `16px / 12px`，**圆角有方向**（CSS 简写顺序 TL TR BR BL）：
  - 用户：CSS 是 `18px 18px 4px 18px`（右下小角）；**本应用按“小角指向头像”改为右上小角**
    `18 4 18 18`（头像在右侧且与气泡顶对齐）
  - char：CSS 是 `18px 18px 18px 4px`（左下小角）；**本应用改为左上小角**
    `4 18 18 18`（头像在左侧且与气泡顶对齐），另加 1px `rgba(255,255,255,0.1)` 边框
- 底色：用户 = **135° 渐变 `#F38181 → #e86a6a`**、白字；char = `#1a1a1a`、白字。
- 文本：14px、行高 1.625；段间距 4px；代码块圆角 12、内距 12、上下外边距 8；行内代码 12px、内距 6/2、圆角 4。
- **图片**：最大高 192px、圆角 12px、下方留 8px。
- **时间戳**：在气泡**下方**（内容列里、气泡外），12px、`#B3B3B3`，与「重新生成」同行 `gap: 8`、上边距 4px。
  格式：`toLocaleTimeString('zh-CN', {hour:'2-digit',minute:'2-digit'})` → `19:49`。
- **重新生成**：12px、`#F38181`、图标 12px + 文字间距 4；仅「最后一条 assistant 且非流式」显示。
- **流式光标**：**7×15px 实心块**、`#F38181`、左边距 2px、0.8s `step-end` 硬闪（不是竖线、不是渐变）。

## 8. 实现时最容易做歪的点

1. 气泡**小圆角的方向**（用户在左下、char 在右下）。
2. 头像与气泡**顶对齐**，不是垂直居中。
3. `max-w-75%` 是相对 **768px 消息列**，不是相对窗口。
4. 背景光晕**非常淡**（3–6%），画重了就完全不对。
5. 玻璃材质（blur + 半透明）——只画纯色会丢层次感。
6. 聚焦环是**外描边**（box-shadow），不是 border（不占布局）。
7. 下拉选中底色是 accent 浅青蓝 ≈`#8FD4E5`，**不是**薄荷 `#95E1D3`；对勾固定灰。
8. 时间戳在**气泡外**（内容列里），与「重新生成」同行。
9. 流式光标是 **7×15 实心块 + 硬闪**。
10. 开关按 shadcn 的 `h-6 w-11`：轨道 44×24、滑块 20、内距 2；开启色 `#F18484` 与珊瑚 `#F38181` 有细微色差。
11. 代码块是**深色**且**圆角**；浅色模式下它依然深色。
12. 顶栏与输入区**全宽**，只有消息列居中。
